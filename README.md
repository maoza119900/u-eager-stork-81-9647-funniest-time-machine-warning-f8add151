The funniest one-line warning label for a time machine, in 120 characters or fewer — 107 characters, to be exact:

> WARNING: Do not step on any butterflies. One traveller did, and now nobody remembers why this label exists.

Why it works: it is phrased like a genuine safety notice, turns a real time-travel hazard (the butterfly effect) into the joke, and saves the surprise — nobody remembers why the label exists — for the last few words.

## Run it

```sh
node main.ts
```

Running it prints the label and writes it to `/output/entry.txt`.
